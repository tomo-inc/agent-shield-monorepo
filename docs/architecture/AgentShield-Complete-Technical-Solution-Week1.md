# AgentShield Complete Technical Solution — Week 1

## I. Technology Selection

| Module | Technology | Reason |
|---|---|---|
| CLI framework | Python + Typer | Same language as existing FastAPI backend; reuses Pydantic |
| AI scanning | Claude API (claude-sonnet-4-6) | Configurable, can be swapped |
| Config validation | Pydantic v2 | Already a project dependency; schema-first |
| Concurrent execution | ThreadPoolExecutor | Parallel checks across sub-modules |
| Coverage parsing | Built-in parsers | JaCoCo XML / pytest-cov JSON / istanbul JSON |
| Notifications | Feishu Webhook | HTTP POST, no SDK required |
| Data storage | Local JSON files | Sufficient for Week 1; migrate to DB in Month 2 |

## IV. Project Configuration Schema

```yaml
# .agentshield/config.yaml (generated by agentshield check or init)

project:
  name: wallet-service
  repo_path: .
  preset: java-maven    # infer-monorepo / java-maven / go / custom

# Only write fields that differ from Preset defaults
commands:
  lint: "mvn checkstyle:check"   # optional override

thresholds:
  mode: auto              # auto | manual
  coverage_tolerance_pct: 5     # gate = baseline - 5%
  coverage_floor_pct: 0         # floor protection, prevents gate going negative
  lint_max_errors: 0
  typecheck_max_errors: 0

timeouts:
  build: 300              # seconds
  test: 600

notify:
  feishu_webhook: $FEISHU_WEBHOOK_URL
```

## V. Core Component Design

### Analyzer (AI scan — called only during init)

```
scanner.py  reads target project:
  ├── directory tree (2 levels deep)
  ├── package.json / pom.xml / pyproject.toml / go.mod
  ├── .github/workflows/*.yml
  └── first 100 lines of README.md

ai_client.py  calls LLM:
  input:  file contents above
  output (Pydantic-constrained):
    {
      preset: "java-maven",
      commands: { build, lint, typecheck, test, coverage },
      coverage_parser: "jacoco-xml",
      confidence: 0.95,
      notes: "found custom checkstyle config"
    }
```

### Checker Pipeline (runs on every check)

```
Unified interface for all Checkers:

class BaseChecker:
    def run(self, config) -> CheckResult:
        # execute command
        # parse output
        # return PASS / FAIL / TIMEOUT / SKIP

CheckResult:
    checker: str
    status: Literal["pass", "fail", "timeout", "skip"]
    detail: str
    duration_sec: float
```

### Orchestrator (scheduling)

```
1. Read .agentshield/config.yaml
2. Deep-merge Preset defaults
3. Pydantic config validation (typos fail immediately)
4. ThreadPoolExecutor runs all Checkers concurrently
5. Per-checker timeout control
6. Aggregate results → Reporter → Notifier → write local files
```

### Baseline (baseline management)

```
First run:
  collect coverage → write .qa-agent/baselines/project.json

Subsequent runs:
  read baseline → gate = max(baseline - tolerance, floor)
  compare current coverage → PASS / FAIL

Explicit update (requires --confirm flag):
  agentshield baseline update → user confirms → overwrite
```

## VI. AI Analyzer Interaction Design (init flow)

```
Step 1  Scan (silent)
  Read files, no confirmation needed

Step 2  Confirm structure
  "Detected java-maven project — is this correct? [Y/n]"

Step 3  Confirm commands
  Show inferred commands, user can edit line by line

Step 4  Collect baseline
  "Run mvn test now to collect baseline (~5 min)? [Y/n]"

Step 5  Configure notifications
  "Set up Feishu Webhook? [1] Configure  [2] Skip"

Step 6  Write config
  Generate .agentshield/config.yaml
  Commit to Git
```
