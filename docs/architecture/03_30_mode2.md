# AgentShield Clean 03_30 Mode 2

## Goal

Ship the first real analyzer module after Mode 1.

Mode 2 adds the internal analyzer flow used by `check` and `init`.

```text
Analyzer snapshot -> LLM analysis -> normalized module suggestions
```

The implementation collects a bounded repository snapshot, calls the configured OpenAI-compatible LLM endpoint, validates the returned JSON structure, and makes the result available to the public commands.

## In Scope

- Repository tree sampling
- Key file sampling
- OpenAI-compatible `/chat/completions` call
- Structured scan report validation
- Human-readable module summary
- Machine-readable scan output

## Deferred

- Interactive confirmation and config editing
- Auto-writing detected module checks back into `.agentshield/config.yaml`
- Multi-turn analyzer repair loop
- Integration into `agentshield init`
- Baseline generation from analyzer output

## Analyzer Input

The scan module reads:

- repository tree up to 3 levels deep
- root config files
- `apps/*` and `packages/*` package manifests
- `.github/workflows/*.yml`
- `openapi/openapi.yaml`
- first 120 lines of selected markdown or manifest files

The snapshot is intentionally bounded so the LLM call remains stable and cheap.

## Analyzer Output

Mode 2 expects JSON with:

- detected project type
- project summary
- module list
- per-module frameworks
- per-module recommended check commands
- evidence paths
- confidence score

## Config Surface

Mode 2 uses the LLM settings already committed in `.agentshield/config.yaml` or the built-in package defaults:

```yaml
llm:
  enabled: true
  provider: openai-compatible
  model: gpt-4.1-mini
  base_url: https://api-infer.agentsey.ai/v1
  api_key: <team key>
```

Environment-based overrides remain available, but they are not required for the shared team configuration.

## Runtime Output

Internal scans write:

- `.qa-agent/scans/<timestamp>.json`
- `.qa-agent/scans/latest.json`

The JSON result is intended to back `check` auto-init and `init --yes`, not to become a public command requirement.
