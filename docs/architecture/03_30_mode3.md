# AgentShield Clean 03_30 Mode 3

## Goal

Turn the public workflow into the two-command model defined by the Clean command design:

```text
agentshield init --yes
agentshield check --strict
```

Mode 3 folds the internal analyzer back into these commands so external users do not need to understand a separate scan command.

## Public Flow

### `agentshield init --yes`

- reads repo snapshot
- runs analyzer
- writes `.agentshield/config.yaml`
- exits after initialization summary

### `agentshield check`

- looks for `.agentshield/config.yaml`
- if found, loads it and runs checks
- if missing and `--no-init` is not set, runs analyzer initialization first
- then runs the generated checks

## Cross-Platform Direction

Mode 3 changes generated checks to use `argv` arrays instead of shell-only command strings.

Example:

```yaml
checks:
  - id: apps-web-test-web
    label: apps/web · test-web
    argv:
      - pnpm
      - run
      - test:web
```

This is the format intended for installable-package delivery on macOS and Windows.
