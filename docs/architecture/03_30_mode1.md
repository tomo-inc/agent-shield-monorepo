# AgentShield Clean 03_30 Mode 1

## Goal

Ship the first usable AgentShield Clean flow on `2026-03-30` without waiting for the full Week 1 architecture.

Mode 1 focuses on a single production path:

```text
agentshield check
```

The command runs the current monorepo quality gate from the repository root, normalizes terminal output, writes a machine-readable run record, and optionally posts a failure webhook.

## Delivery Boundary

### In Scope

- `packages/cli` Python package with executable `agentshield`
- `agentshield check`
- Typed config loading from `.agentshield/config.yaml`
- Config placeholders for future AI scan integration
- Configurable webhook delivery for failed checks
- Run records written under `.qa-agent/runs/`
- Root quality gate integration:
  - `pnpm lint`
  - `pnpm typecheck`
  - `pnpm test`
  - `pnpm check:openapi`

### Deferred After Mode 1

- `agentshield init --yes`
- Interactive project discovery
- LLM-powered scan execution
- Baseline management and `baseline update`
- Historical CLI report command
- Feishu-specific formatting
- Cross-project concurrency

## Why Mode 1 Is Cut This Way

The design document describes a full CLI system, but the repository does not yet contain `packages/cli`.

The fastest safe path is to wrap the already-working monorepo gate and make it runnable as a first-class CLI command. That gives the team:

- one entrypoint
- predictable output
- CI-compatible exit codes
- a stable config surface for later AI scan work
- webhook plumbing that does not need to be redesigned later

## Mode 1 Command Contract

### Supported Command

```bash
uv run --project packages/cli agentshield check
```

### Supported Flags

- `--config`: override the config path, default `.agentshield/config.yaml`
- `--strict`: return exit code `1` when any check fails

### Default Behavior

If `.agentshield/config.yaml` exists, AgentShield loads it.

If the file is missing, AgentShield falls back to the built-in monorepo preset:

- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm check:openapi`

## Config Surface

Mode 1 adds a committed config template at `.agentshield/config.yaml`.

### Runtime Sections

```yaml
version: 1
project:
  name: agent-shield-monorepo
  root: .

checks:
  - id: lint
    label: Lint
    run: pnpm lint
    timeout_sec: 1200
  - id: typecheck
    label: Typecheck
    run: pnpm typecheck
    timeout_sec: 1200
  - id: test
    label: Test
    run: pnpm test
    timeout_sec: 1800
  - id: openapi
    label: OpenAPI
    run: pnpm check:openapi
    timeout_sec: 600

llm:
  enabled: true
  provider: openai-compatible
  model: gpt-4.1-mini
  base_url: https://api-infer.agentsey.ai/v1
  base_url_env: AGENTSHIELD_LLM_BASE_URL
  api_key: <committed team key>
  api_key_env: AGENTSHIELD_LLM_API_KEY

notify:
  enabled: false
  webhook_url_env: AGENTSHIELD_WEBHOOK_URL
  send_on:
    - failure
```

## LLM Parameters For The Next Module

AI scanning is not executed in Mode 1, but the required configuration is locked now so the next module can use it directly:

- `llm.base_url`
- `llm.api_key_env`
- `llm.model`

The repository now carries the team-shared OpenAI-compatible `base_url` and API key in `.agentshield/config.yaml`, so teammates can pull the config directly without local secret bootstrapping.

Environment-based overrides still exist in the schema, but they are optional rather than required for the shared team setup.

## Webhook Behavior

Mode 1 includes webhook support in the main `check` flow.

If `notify.enabled` is `true` and a webhook URL is available, AgentShield posts a JSON payload after the run when the configured trigger matches the result.

The initial payload includes:

- project name
- overall status
- failed check ids
- run timestamp
- run record path

## Run Output

Each execution writes:

- terminal summary for humans
- JSON run record under `.qa-agent/runs/`

This keeps Mode 1 compatible with a later `agentshield report` command without adding that command yet.

## Verification

Mode 1 is only complete when all of the following pass:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm check:openapi
pnpm run ci
```
